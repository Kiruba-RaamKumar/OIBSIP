# Task 4 – Unveiling the Android App Market
## Google Play Store Analysis

### Project Overview
This project analyzes Google Play Store applications to explore app categories, ratings, reviews, installations, and pricing.

### Objectives
- Explore application categories.
- Analyze app ratings and reviews.
- Study installation patterns.
- Compare free and paid applications.
- Identify meaningful patterns in the Android app market.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Project Workflow
1. Data loading
2. Data inspection
3. Data cleaning
4. Exploratory Data Analysis
5. Data visualization
6. Insights and conclusions
