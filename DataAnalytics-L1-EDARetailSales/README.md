
# Retail Sales Exploratory Data Analysis

## 1. Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a Retail Sales dataset using Python.

The goal is to understand sales patterns, customer purchasing behaviour, and business performance through data analysis and visualization.

## 2. Project Objectives
- Understand the retail sales dataset.
- Identify and handle missing values.
- Remove duplicate records.
- Analyze sales trends.
- Identify top-selling products.
- Understand customer purchasing behaviour.
- Generate meaningful business insights.

## 3. Technologies Used
