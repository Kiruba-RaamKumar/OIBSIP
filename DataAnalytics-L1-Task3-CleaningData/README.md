# OIBSIP – Data Analytics Internship

## Task 3: Data Cleaning

### Project Overview
This project focuses on cleaning and preprocessing a Cafe Sales dataset using Python and Pandas.

### Objectives
- Identify missing values.
- Detect duplicate records.
- Handle invalid values such as ERROR and UNKNOWN.
- Convert incorrect data types.
- Handle missing numerical and categorical values.
- Detect outliers.
- Prepare a clean dataset for analysis.

### Dataset Information
- Dataset: Cafe Sales
- Original Records: 10,000
- Columns: 8

### Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Data Cleaning Steps
1. Import libraries.
2. Load the dataset.
3. Inspect rows and columns.
4. Identify missing values.
5. Handle invalid entries.
6. Convert data types.
7. Handle missing values.
8. Check and remove duplicates.
9. Detect outliers.
10. Validate and export the cleaned dataset.
