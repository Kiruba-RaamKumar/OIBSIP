# Wine Quality Prediction | Machine Learning

## Project Overview
This project focuses on predicting red wine quality using machine learning techniques. It explores physicochemical properties of wine and their relationship with wine quality.

## Objectives
- Explore and understand the wine quality dataset.
- Perform statistical analysis and data exploration.
- Visualize relationships between wine properties and quality.
- Identify important features.
- Build and compare machine learning classification models.

## Dataset
- Dataset: Red Wine Quality Dataset
- File: `winequality-red.csv`
- Target variable: `quality`
- Input features: 11 physicochemical properties.
