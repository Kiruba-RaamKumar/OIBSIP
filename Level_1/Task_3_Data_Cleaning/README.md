# Data Cleaning Project

## OIBSIP – Task 3

### Objective
Demonstrate professional data cleaning skills by transforming a messy Cafe Sales dataset into a clean, analysis-ready dataset.

### Tools Used
- Python
- Pandas
- NumPy
- Google Colab

### Project Workflow
1. Dataset loading and inspection.
2. Data quality report.
3. Missing value handling.
4. Duplicate detection.
5. Data type correction.
6. Data cleaning and preprocessing.
7. Exporting cleaned dataset.

### Project Files
- OIBSIP_DataAnalytics_Task3_CleaningData.ipynb
- Cleaned_Cafe_Sales.csv

### Conclusion
The project demonstrates data cleaning and preprocessing techniques to prepare reliable data for further analysis.
